# Olimp

Навчальний сайт фітнес-клубу Olimp для лабораторних робіт №7 і №8 з технологій веброзробки та дизайну.

Сайт використовує HTML, CSS, Tailwind CSS і JavaScript. Головна сторінка — `index.html`. Решта HTML-файлів містять інформацію про клуб, абонементи, тренерів, зали й контакти. Стилі зберігаються в `css/`, скрипти — в `js/`, зображення та шрифти — в `assets/`.

## Локальний перегляд

Відкрий корінь репозиторію у VS Code і запусти `index.html` через Live Server. Для перегляду окремої сторінки використовуй навігацію сайту.

## Публікація

Готовий CSS Tailwind входить до репозиторію, тож для публікації сайту окрема збірка не потрібна.

- GitHub Pages — публікація з кореня гілки `main`.
- Netlify — публікація з кореня репозиторію з порожнім полем команди збірки.
